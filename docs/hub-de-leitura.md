# Hub de Leitura

## Objetivo
Sistema educacional de biblioteca digital usado para prática de QA.

## Perfis
- Usuário comum
- Administrador

## Fluxos principais
- Login
- Cadastro
- Catálogo
- Cesta
- Reserva/checkout
- Painel administrativo

## Aplicação local
- URL: http://localhost:3000
- API Docs: http://localhost:3000/api-docs

## Observações para QA
- Priorizar testes funcionais E2E.
- Validar textos visíveis, URLs, mensagens e estados da interface.
- Não expor senhas em evidências.
